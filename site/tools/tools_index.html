Individual

Taxpayer Calculator

Simulate the WDT tax profile for a single taxpayer under Route C (equity-transfer mechanism). Set starting wealth, growth rate or historical series, holding period, and declaration ratio α. Always shows the honest-declaration (α = 1) baseline alongside the selected scenario.

National

Revenue Calculator

Aggregate revenue across the full UK taxable wealth distribution (10 brackets, 4 return tiers). Set rate parameters, growth scenario, budget baseline, and SWF sizing. Compare modelled WDT revenue against current UK tax receipts.

Tools use wdt_core.py and rates_model.py from the WDT research codebase, loaded unmodified at runtime. First load requires ~10s to initialise the Python runtime; subsequent runs in the same session are fast.
