## The argument

```{=html}
<div class="wdt-argument-spine">
  <p class="wdt-spine-intro">The paper domains follow from the proposition. Each domain is necessary, not optional.</p>

  <div class="wdt-spine-row">
    <span class="wdt-spine-if">If WDT taxes annual changes in net wealth</span>
    <span class="wdt-spine-arrow">→</span>
    <span class="wdt-spine-then">the change must be measurable</span>
    <span class="wdt-spine-domain">→ Valuation domain</span>
  </div>

  <div class="wdt-spine-row">
    <span class="wdt-spine-if">If it taxes gains and refunds losses</span>
    <span class="wdt-spine-arrow">→</span>
    <span class="wdt-spine-then">the refund must be funded</span>
    <span class="wdt-spine-domain">→ Revenue domain</span>
  </div>

  <div class="wdt-spine-row">
    <span class="wdt-spine-if">If capital accumulates in a public fund</span>
    <span class="wdt-spine-arrow">→</span>
    <span class="wdt-spine-then">someone must govern it</span>
    <span class="wdt-spine-domain">→ Governance domain</span>
  </div>

  <div class="wdt-spine-row">
    <span class="wdt-spine-if">If people respond behaviourally</span>
    <span class="wdt-spine-arrow">→</span>
    <span class="wdt-spine-then">responses must be understood and designed around</span>
    <span class="wdt-spine-domain">→ Behavioural domain</span>
  </div>

  <div class="wdt-spine-row">
    <span class="wdt-spine-if">If this is to become law</span>
    <span class="wdt-spine-arrow">→</span>
    <span class="wdt-spine-then">a credible transition path must exist</span>
    <span class="wdt-spine-domain">→ Implementation domain</span>
  </div>
</div>
```

## If you have 1–2 hours — the core sequence

These five papers establish the full architecture. Reading them in order gives a complete picture of mechanism, foundations, valuation, governance, and fiscal viability.

1. [White Paper (WP)](wp.html) — mechanism design, principal objections, implementation pathway
2. [Moral Foundations (MF)](mf.html) — why the delta base, and the cooperative architecture
3. [Valuing Wealth (VAL)](val.html) — how the four valuation routes work
4. [Constitutional Governance (GOV)](gov.html) — how the SWF is governed and protected from capture
5. [Rates and Revenue (RATES)](rates.html) — what the WDT raises and under what assumptions

## What the project does not yet know

```{=html}
<div class="wdt-open-questions">
  <p class="wdt-oq-header">Open questions</p>
  <p class="wdt-oq-intro">These are questions the papers have identified as unresolved. They are stated here because intellectual honesty requires it, not despite it.</p>
  <ul class="wdt-oq-list">
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      The formal welfare comparison between a delta base and a consumption tax has not been completed. <a href="lr-a.html">→ LR.A §2.2</a>
    </li>
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      The Domar-Musgrave extension to a progressive delta-based wealth tax has not been formally modelled. <a href="lr-a.html">→ LR.A §2.1</a>
    </li>
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      The cross-base fiscal externality of migration has not been incorporated into any behavioural revenue model. <a href="lr-a.html">→ LR.A §3.2</a>
    </li>
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      Optimal rate design for the progressive delta schedule under behavioural responses has not been solved. <a href="rates.html">→ RATES</a>
    </li>
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      The valuation protocol for illiquid partnership interests and carried interest has not been finalised. <a href="val.html">→ VAL</a>
    </li>
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      The constitutional entrenchment mechanisms for the SWF have not been stress-tested against UK parliamentary sovereignty doctrine. <a href="gov.html">→ GOV</a>
    </li>
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      The interaction between WDT and existing pension tax relief structures has not been modelled. <a href="scope.html">→ SCOPE</a>
    </li>
    <li class="wdt-oq-item">
      <span class="wdt-oq-marker">○</span>
      The minimum fund capitalisation required to maintain refund credibility through a 2008-scale crash has not been formally derived. <a href="rates.html">→ RATES</a>
    </li>
  </ul>
</div>
```
