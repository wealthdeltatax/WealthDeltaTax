Contains public sector information licensed under the Open Government Licence v3.0 (ONS). JST Macrohistory R6 is CC BY-NC-SA 4.0 (Jorda, Schularick and Taylor): cite only, non-commercial. IFS and WID rows are cite only. The pack stays a private input of the repo.

Each file's `retrieved` date is the day its source file entered this repository (git history, renames followed); a file with no source file carries the build date.

wealth_distribution.csv base rows (brief 067c): wealth_total D1 to D10 from totalwealthtables.xlsx Table 2.2 (block 1, last column, GBP million, over 1000) and all from Table 2.1 row 8; households from Table 2.1 row 29 (weighted frequency, 26,991,000), each decile the total divided by ten (a decile holds a tenth of households by definition; no table prints a count per decile); no adults rows (no held table gives adults by decile); median_house_price GBP 300,000 is England, year ending Sept 2025, all dwellings, from `Research/Housing affordability in England and Wales 2025.pdf` (the existing-dwelling median in `medianpricepaidforadministrativegeographiesexisting.xlsx` table 1a is GBP 297,000); gdp is the mean of financial years 2020-21 (2,085.204) and 2021-22 (2,337.757) GBP bn in `Revenue composition spreadsheet.xlsx` sheet Total revenues, column G, nominal as published. The file is cite only because the GDP series comes from the IFS spreadsheet.

returns.csv gdp_pc (brief 070c) is the JST series rgdpmad, real GDP per head, a level in the units JST publishes (the repo's description of the variable says Maddison, 1990 USD; the held file carries no unit label), JSTdatasetR6.xlsx Sheet1, GBR rows 1870 to 2019 (2019 is row 1510). public_expenditure.csv holds one row, function total, fiscal_year 2019 (a calendar year, v2's exp_ref_year): pct_gdp is 100 x JST expenditure over gdp, 2019, cells expenditure 830.452 and gdp 2,255.283, = 36.82. JST is used first, as v2 did. Cross-check, not stored: PSS_May_2024_TES_UPDATED.xlsx Data_for_charts, Total Managed Expenditure over Nominal GDP is 39.58 for 2019-20 (888.4 / 2,244.5) and 39.48 for 2018-19; JST general government expenditure and TME differ in definition and in calendar against fiscal year. gbp_bn is left empty: the JST description calls the unit millions but the GBR values are billions.

cell_weights.csv and band_composition.csv (brief 109c, pack_version 2) are read from the held derived files `docs/research/data/104r/cell_weights.csv` and `docs/research/data/102r/band_composition_by_pack_band.csv`. cell_weights are persons aged 16+ placed by household wealth band and economic stage (retired, or not retired = working, unemployed and inactive not retired): a person-based proxy, not households; max_rounding is the 102r bound in persons. band_composition holds the shares of band net wealth, April 2020 to March 2022, one decimal as printed (they sum to 100 within 0.5); there is no debt row because the survey nets debt inside property and net financial wealth.

decile_composition.csv (brief 115c, pack_version 3) is read from the held derived file `docs/model-v3/kernel-wiring/decile_composition.csv` (112r): the shares of each decile's net wealth by class, WAS Round 8 Table 2.2, April 2020 to March 2022, two decimals as held, negative shares included (D1 holds net debt in property and net financial wealth: property -4.72, net financial -104.92, physical 169.46, pension 40.18). Each decile sums to 100 within rounding. D10b and the Rich List tiers take the D10 mix: an assumption, stated in the `basis` of the D10 rows (the survey misses business wealth).
