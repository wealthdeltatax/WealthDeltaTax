# Wealth Delta Tax

A series of papers (main papers plus appendix companions) proposing an accrual-basis wealth tax with symmetric loss refunds and a sovereign wealth fund. Live site: https://wealthdeltatax.org

- `source/` the papers (Markdown, canonical)
- `pipeline/` builds the Quarto site, PDFs and Zenodo uploads from `source/`
- `site/` hand-written site pages and styles
- `registry/` paper list, contents, anchors, bibliography, crosslinks
- `model/` Python simulation behind the papers' figures and tables
- `docs/` plans, briefs, decisions and agent guides

Working with an agent in this repo: start at `START_HERE.md`.
