# Lessons so far (guru, 2026-11-16)

Working list for the stage E synthesis. Neither model is fixed; the point is what v3 must do differently. Sources: `v1-inventory.md`, `v1-errors.md`, `v2-inventory.md`. Stage D is merged and has confirmed or extended lessons 6, 6a, 6b and 6c; lessons 1 to 5, 7 and 8 stand on stages A to C.

1. **One definition per metric, written where code and paper both point to it.** C.1 is divided by TW(1) in `wdt_core.run_pair` (paper 5 tables) and by TW(alpha) in `wdt_analytics.c1` (paper 9) and in paper 5a's definition. The tolerant zone ends at 1.80 or 1.85 depending on the path (v1-errors B1). The `run_pair` docstring says the refactor changed it; nothing else was updated.
2. **Layers stayed clean only in v2, and only when someone wrote the rule down.** v1 has core-to-core and presentation-to-core imports (C3), four JSON sanitisers that behave differently (C1, B9) and capitalisation logic in four places (C5). v2's imports follow the layering (v2-inventory section 2.2).
3. **Hardcoded numbers and prose drift away from the parameter file.** `sweeps_core` marks tau_0 = 20% as canonical; the TOML says 15% (B7). The synthetic scenario's comments say 2% and 4%; the values are 7% and 8% (B8). Typed numbers sit in presentation text (A6). A table's N in its title differs from the N it ran at (B5).
4. **A renamed or moved file broke the pipeline with no test to catch it.** `rates_core` became `rates_core1.py`; 8 of 16 `run_all` entries cannot start (stage A) and a test file cannot import (E4). v2 has no run script at all, and the four tests its reference doc names do not exist (v2-inventory section 7).
5. **A silent convention change makes two models disagree on the same inputs.** v2 carries the post-surrender basis; at alpha 1.5, N 30, `net_pct` is +0.0132 (v2) against +0.0093 (v1). The note explaining it, `BASIS_CHANGE.md`, is cited and not tracked.
6. **Scope grew without a check that any paper needed it.** v2's model Python is no larger than v1's (17,729 against 18,136 lines), but its parameter file is 1,839 lines against 554 (58% `[rates]`, 101 scenarios, 27 never used). The three largest sources of complexity are the output layer (5,150 lines for 55 figures and 56 tables), `valgen_core` (3,353 lines, 23% of it seven validators) and `eval_core` (2,718 lines, 15% of v2's Python, cannot import). Confirmed by stage D (`v2-complication.md` sections 1 and 3).
6a. **Design choices were made that no paper states.** The gain ladder, the fresh-entrant heir rule and the strategy verdicts BRG, HSC, SPT and SST appear in 0 of the papers; v2's baseline is not the papers' rate function (stage C fact 4, stage D section 2 rows 3, 4, 7).
6b. **Code was carried forward without being ported.** `eval_core.py` still needs `wfr_core` and the retired TOML sections, and nothing imports it. A placeholder HLC pair is wired in and skipped.
6c. **Tests did not travel.** v1 had 320 passing assertions on its helper modules; v2 has one drift test (passes with a warning) and the four tests its reference doc names do not exist. So there is no check that the two v2 cores agree on the same line, and no check that v2 and v1 agree where they should (stage D section 4).
7. **Outputs were not tied to the papers.** Paper 19 embeds three figures nothing produces and three with a doubled `fig_` prefix; figure prefixes and numbers are inconsistent across five families (D4). v2 tracks no outputs, so nothing can be compared with the papers.
8. **Import side effects and stale docs.** Two v2 WID scripts rewrite data files on import. `WDT_Model_Reference.md` names scripts that no longer exist (E1).

For v3 (011g) this implies: a metric register that papers and code both cite; a run script and a smoke test that fail loudly on a rename; every output named for the paper element it feeds; a parameter file with no duplicated or stale values; and a written reason for any change of convention; a stated reason for every part (what paper element needs it), with anything unused or unported removed; and tests that carry over or are rewritten before a module is retired.
