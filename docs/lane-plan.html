    Commands and how-to (paste-ready)

    Run from the repository folder. Examples are PowerShell; each button copies one block.

    1. Get the latest code

    git checkout main
git pull

    A tree with local changes: git status first. Agents work on a branch named brief/NNN-slug (the brief's number, no letter) and merge their own finished brief into main by the auto-merge rule in AGENTS.md.

    2. Check the papers

    python pipeline/check_wdt_format.py source/<paper>.md
python pipeline/wdt_crosslinks.py check

    The crosslink check is expected to report errors until the paper rewrite lands (retired brief 007w).

    3. Build the site

    pipeline\build.bat
pipeline\build_and_render.bat

    The first builds without rendering, the second renders. main deploys on every push and the Action runs only on main: agents build locally before merging a site change, then watch the Action and revert if it fails.

    4. Agents

    Open the skill named by the letter after the brief number: g wdt-guru, w wdt-write, c wdt-code, r wdt-research, s wdt-web. Start an agent with:

    Read AGENTS.md, then docs/agents/<role>.md, then the brief docs/briefs/<NNNx-slug>.md. Do only that brief. Stop after one stage and write the change report.

    Paste to an agent when the usage meter is low, and to the next agent to resume (full text in docs/agents/handover.md):

    Stop work now. Commit everything as wip, push the branch, fill in the brief's progress block, then stop. Do not run checks.
    Read the brief and its progress block, `git log origin/main..HEAD`, and `git diff --stat origin/main`. Continue from Next. Do not re-explore. Run the Resume commands first.

    5. Housekeeping

    git branch -r --merged origin/main
git remote prune origin

    The first lists remote branches already merged into main (delete them on GitHub when you are sure); the second drops stale local tracking refs.
