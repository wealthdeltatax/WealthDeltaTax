## I would actually define three different "required reading" standards

### 1. The **WDT literacy test**

Someone who says *"I've read the WDT proposal"* should have read:

**WP → MF → VAL → CORP → GOV → RATES → BEHAV → POL → PHASE1**

That's the minimum sequence I would use for an MP, journalist, general economist, serious critic, or prospective collaborator.

It is about **90,000 words**, so this is no longer a casual introduction. But importantly, it means the reader has encountered:

1. what WDT is;
2. why it exists;
3. how wealth is measured;
4. how corporate wealth enters the system;
5. who controls the resulting public capital;
6. whether the fiscal arithmetic works;
7. how people might respond;
8. how the system survives politically;
9. and how you actually get from the current system to WDT.

That is a much more defensible definition of "understanding the proposal" than five papers.

### 2. The **serious economic challenge**

For someone whose job is to try to break the economics:

**WP → MF → LR.A → LR.B → VAL → VAL.A → CORP → CORP.A → RATES → RATES.A → SWEEPS → SWEEPS.A → BEHAV → CLOSE → FM → MOD**

Then selectively:

**JUR, GOV, SCOPE, ENV**

This is the group I would want an economist or public-finance researcher to read before saying *"this cannot work"*.

The particularly important change from your current five-paper sequence is **LR.A + BEHAV + CORP + SWEEPS**.

Those are where a critic is most likely to discover that a seemingly obvious objection is already considered, or alternatively find a genuine unresolved weakness. The project explicitly identifies several unresolved areas, including welfare comparison, progressive Domar-Musgrave modelling, migration externalities, optimal rate design, illiquid partnership valuation, parliamentary sovereignty, pensions, and crash-scale refund capitalisation. ([The WDT][2])

### 3. The **full architecture / peer-review standard**

For someone effectively acting as a hostile peer reviewer:

**Everything except ADD**, with the appendices read immediately after their parent paper.

That means:

> WP
> ↓
> MF / LR.A / LR.B / JUR
> ↓
> VAL → VAL.A → VAL.B
> ↓
> CORP → CORP.A
> ↓
> GOV → GOV.A → GOV.B
> ↓
> RATES → RATES.A → SWEEPS → SWEEPS.A
> ↓
> BEHAV
> ↓
> CLOSE → PHASE1
> ↓
> POL / ENV / FM / MOD
> ↓
> SCOPE

**ADD stays outside the required corpus** because it is explicitly a draft implementation-calibration document rather than a structural component of the argument. The corpus currently marks both SCOPE and ADD as drafts, but SCOPE is conceptually important enough that I would still make it required for a serious reviewer. ([The WDT][1])

# One change I would make to the website

I think the existing statement:

> "For first-time readers, the recommended sequence is: WP → MF → VAL → GOV → RATES"

is now **too compressed for the size of the corpus**. ([The WDT][1])

It works as a **1–2 hour introduction**. It does not work as a definition of what someone needs to read to understand the research programme.

I'd replace it with something like:

| Reader                                   | Required sequence                                                                         |
| ---------------------------------------- | ----------------------------------------------------------------------------------------- |
| **New reader**                           | WP → MF → VAL → GOV → RATES                                                               |
| **Serious reader**                       | WP → MF → VAL → CORP → GOV → RATES → BEHAV → POL → PHASE1                                 |
| **Economist / tax researcher**           | Serious sequence + LR.A → LR.B → VAL.A/B → CORP.A → RATES.A → SWEEPS/A → CLOSE → FM → MOD |
| **Legal / constitutional researcher**    | Serious sequence + JUR → CORP.A → GOV.A/B → SCOPE                                         |
| **Political / institutional researcher** | Serious sequence + JUR → POL → GOV.A/B → PHASE1 → FM → MOD → SCOPE                        |
| **Full peer review**                     | All active papers; appendices after parent papers                                         |

That gives the corpus a useful property: **there is no pretence that everyone needs to read 300,000 words, but there is also no ambiguity about what "I've read the WDT research" means.**

And I think **CORP deserves to be in the serious-reader core now**. The current corpus explicitly treats corporate architecture as a separate domain, and the paper addresses the central practical problem of attributing wealth held through companies to individual taxpayers. ([The WDT][2])

One other thing I'd add: **LR.A should probably come much earlier than it currently appears in the recommended reading experience.** It is the paper that tells an intelligent outsider *where the author is making a claim, where the literature already answers the question, and where the author knows the answer is incomplete*. That makes the rest of the corpus substantially easier to evaluate rather than simply asking the reader to trust the architecture. ([The WDT][3])
